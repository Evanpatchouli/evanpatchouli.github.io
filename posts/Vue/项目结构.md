## Vue 3 项目结构

Vue 3 项目的基本结构如下：

```
my-vue-app/
├── node_modules/
├── public/
├── src/
│   ├── assets/
│   ├── components/
│   ├── App.vue
│   ├── main.js
│   └── router/
├── .gitignore
├── index.html
├── package.json
├── README.md
└── vite.config.js
```

### 目录结构说明

- `node_modules/`：存放项目依赖的第三方库和模块。
- `public/`：存放静态资源文件，如图片、字体等。这些文件会被直接复制到项目的输出目录中。
- `src/`：存放项目的源代码。
  - `assets/`：存放项目的静态资源文件，如图片、字体等。这些文件会被打包到项目的输出目录中。
  - `components/`：存放项目的 Vue 组件。
  - `App.vue`：项目的根组件。
  - `main.js`：项目的入口文件，用于创建 Vue 实例并挂载到 DOM 元素上。
  - `router/`：存放项目的路由配置。
- `.gitignore`：Git 的忽略文件，用于指定哪些文件或目录不应该被 Git 跟踪。
- `index.html`：项目的入口 HTML 文件，用于加载项目的 JavaScript 和 CSS 文件。
- `package.json`：项目的配置文件，用于管理项目的依赖和脚本。
- `README.md`：项目的说明文档。
- `vite.config.js`：Vite 的配置文件，用于配置项目的构建和开发环境。

`src`目录中的 `router/` 文件夹存放项目的路由配置，这个文件夹中通常会有一个 `index.js` 文件，用于定义项目的路由规则和路由组件。
